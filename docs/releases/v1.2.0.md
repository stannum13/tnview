# TNView v1.2.0

TNView v1.2.0 expands the terminal-first diagnostics workflow with oscilloscope
views, better interactive replay navigation, richer adapter helpers, and more
machine-readable discovery commands.

## Highlights

- `tnview scope` renders static signal windows for entropy, chi, truncation,
  fronts, selected bonds, and marker ticks.
- `tnview animate` can filter frames by time, focus selected signals, and show
  oscilloscope-style signal strips.
- Interactive replay gained command mode, jump-to-time, scroll support, and a
  toggleable scope panel.
- Diagnostic output now supports threshold profiles, categories, suppressions,
  and baseline-vs-candidate comparison.
- quimb and TeNPy adapters are more ergonomic while remaining dependency
  optional.
- `tnview recipes`, `tour --json`, `examples --json`, `focus --list --json`,
  and `sketch --json` improve onboarding and scripting.

The package version is `1.2.0`. The run-log telemetry schema remains `0.1`.

## First Run

```bash
python -m pip install -e .
tnview recipes
tnview sketch "mps sites=48 chi=128 profile=front" --interactive
tnview compare examples/quimb_tnoptimizer_run.jsonl examples/dmrg_bad_run.jsonl --diagnostics
```

```bash
make check
make smoke
```
